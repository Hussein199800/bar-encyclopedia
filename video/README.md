# فيديو تعريفي بالموسوعة — مشروع الإنتاج

ينتج هذا المجلد فيديو شرحياً عن الموسوعة بنسختين:

- **كاملة:** نحو ٥ دقائق.
- **مختصرة للتعريف:** نحو ٤٠ ثانية.

التسجيل حقيقي: الموقع نفسه يعمل داخل «مسرح» تصوير (`stage.html`)، وتنفّذ الخطوات المكتوبة نقرات وكتابة حقيقية فيه، متزامنة مع التعليق الصوتي.

## الملفات

| الملف | الدور |
| --- | --- |
| `scenes.mjs` | السيناريو: جمل التعليق الصوتي، وما يحدث على الشاشة مع كل جملة، للنسختين |
| `stage.html` | مسرح 1920×1080 بهوية «الجواهر»: إطار متصفح، هاتف، بطاقات، ترجمة، مؤشر، تكبير |
| `produce.mjs` | يولّد الصوت، ويسجّل كل مشهد، ثم يركّب المونتاج بـ ffmpeg |
| `tts.py` | صوت عربي سوري (`ar-SY-LaithNeural`) عبر edge-tts |
| `music.py` | موسيقى خلفية هادئة مولّدة برمجياً، بلا أي حقوق خارجية |

## التشغيل

```sh
pip install edge-tts           # مرة واحدة
cd video && npm install        # مرة واحدة (Playwright)
cd .. && python3 -m http.server 8811 &   # من جذر المستودع
cd video && npm run full       # أو: npm run short
```

**المخرجات في `video/out/`:**
- `bar-encyclopedia-explainer.mp4` و`.srt` (الكاملة).
- `bar-encyclopedia-teaser.mp4` و`.srt` (المختصرة).

**المواصفات:** H.264 بدقة 1080p و30 إطاراً في الثانية، وصوت AAC بمستوى −16 LUFS، وملف ترجمة SRT.

## التعديل

- **لتغيير جملة:** عدّلها في `scenes.mjs`. يُعاد توليد صوتها وحدها، لأن الأصوات محفوظة حسب نصها.
- **لتغيير الصوت:** `VOICE=ar-SY-AmanyNeural npm run full` (صوت نسائي سوري).
- **للتسجيل من الموقع المنشور بدل النسخة المحلية:** `SITE_ORIGIN=https://hussein199800.github.io/bar-encyclopedia`، ويُغيَّر مسار `stage.html` تبعاً لذلك.
- **مدة كل مشهد** تُحسب تلقائياً من طول جمله. التوقيتات المقيسة فعلاً تُكتب في `out/<النسخة>/timeline.json`.
