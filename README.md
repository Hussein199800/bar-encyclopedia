# موسوعة نقابة المحامين السورية

موقع عربي ثابت يجمع النصوص الكاملة لقانون تنظيم مهنة المحاماة (30/2010) والنظام الداخلي والنظام المالي وأنظمة صناديق التعاون والإسعاف والتكافل والمرجع القانوني للوكالات القضائية، مع:

- فهرس هرمي لكل وثيقة وبحث عربي في كل المواد.
- 56 موضوعاً مشروحاً و15 دليلاً للمسؤوليات والصلاحيات — كل بند مربوط بمادته وصفحتها.
- حاسبات وقوائم تدقيق تعمل وفق الأرقام المنصوص عليها فقط.

افتح `index.html` في المتصفح، أو انشره على GitHub Pages.

> النصوص منقولة من الملفات الرسمية المرفقة في `sources/`. الوثائق المصورة منسوخة بصرياً وتحتاج مراجعة مقابل الأصل. المحتوى إرشادي ولا يغني عن الجهة المختصة.
