# bar-encyclopedia — موسوعة نقابة المحامين السورية

Static Arabic (RTL) encyclopedia of the Syrian Bar Association's law, regulations and funds. Plain HTML/CSS/JS, no build step, no backend. Separate project from Work_1 (the audit app) but shares its design system «الجواهر».
Planned hosting: GitHub Pages → https://hussein199800.github.io/bar-encyclopedia/
The user (حسين الطويل، فرع إدلب) writes in Arabic; reply in Arabic.

## ⚠️ Rule #1 — no fabrication
Every legal, financial or procedural statement comes ONLY from the 7 source documents in `sources/`. Every item in topics/roles/tools carries refs (`"law:9 internal:8"`); `node tools/validate.js` must pass (0 broken refs, no item without a ref). Anything without a source goes into `gaps` («يحتاج تحقق»), never stated as a rule. Keep the three content kinds visually distinct: نص حرفي (verbatim) / شرح مبسط / مثال افتراضي.
- No pension calculator: «قانون تقاعد المحامين» is NOT among the sources. Only the Takaful retirement grant (tak:18) is documented.
- Where the source is ambiguous (fund entry fees over 40) or inconsistent (agency fee totals ≠ sum of items), show both and flag — do not pick silently.

## ⚠️ Same origin as Work_1
Both sites live on `hussein199800.github.io`, so they SHARE localStorage/IndexedDB. This site must only use keys prefixed `enc_` (currently `enc_ui_theme`, `enc_ui_check_<toolId>`), never touch `audit_*`, `currentUser`, `activeSection` or any other key, and never call `localStorage.clear()`. It stores UI prefs only.

## Structure
- `index.html` shell (sidebar nav + doc tree, top search) · `style.css` (tokens copied verbatim from Work_1 + encyclopedia components; breakpoints 1280/1024/640; light/dark via `data-theme`) · `app.js` (hash router `#/…`, Arabic-normalized search with light stemming, views, tools).
- `data/docs.js` — GENERATED by `tools/build_data.py` (do not edit by hand): `window.ENC_DOCS` = 7 docs × articles `{key, num, label, page, bookPage, part, chapter, section, paras[]}` + toc + `missing` + `unclear`.
- `data/content-core.js` (cats, roleGroups, roles) · `data/topics-a/b/c.js` (topics) · `data/tools.js` (tool list, checklists, deadlines, agency fee tables, changelog).
- Doc ids: `law` (القانون 30/2010), `internal` (النظام الداخلي), `fin` (النظام المالي; `t1` = chart of accounts), `coop`, `amb`, `tak`, `agn` (agency reference; rules `r1..r51`, fees `fees1..fees8`, `intro`, `rules`).
- Routes: `#/`, `#/docs`, `#/doc/:id`, `#/doc/:id/:key`, `#/topics`, `#/cat/:id`, `#/topic/:id`, `#/roles`, `#/role/:id`, `#/tools`, `#/tool/:id`, `#/search?q=&type=&doc=&cat=`, `#/about`.

## Source pipeline (tools/)
- law & internal: text-layer PDFs. `extract_text.py` rebuilds lines from character positions (pdftotext reverses Arabic ligatures: «سجالت» → «سجلات»); `parse_text.py` → parts/chapters/articles. Glued words like «سندالوكالة» are in the source PDF itself.
- fin, coop, amb, tak, agn: scanned (or broken-font) PDFs, transcribed visually page by page into `tools/transcribed/*.txt` (format documented at the top of `build_data.py`; `[؟]` = unclear word). Status: awaiting human review against the originals.
- Internal regulation is missing articles 32, 33, 54–63 in the supplied copy, and cites article numbers of the repealed law 39/1981.
- Rebuild: `python3 tools/build_data.py && node tools/validate.js`.
